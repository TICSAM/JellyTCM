# 水母中医 · JellyTCM

> 一个能装进 U 盘的电子中医学习手册：六经辨证 → 方证对应 → 药材炮制，配艾宾浩斯记忆练习与错题本。
> 纯静态网页，零依赖、零安装、零联网。双击 `index.html` 就能用。

当前版本：**v2.13**　｜　方剂 **341** 首（含**王付 15 基础方**标注）· 药材 **497** 味（**490 味有实拍图**，共 **520** 张，约 31 MB）· 汤头歌诀 **341** 首（与方剂 1:1）· 《伤寒论》条文 **170** 条（**逐条精讲**：白话 · 辨证眼目 · 用药与误治 · 病案 · 一句话记忆）· 现代病 **64** 个 /**254** 个证型 · 医案 **62** 则 · 经穴 **389** 个 · 脉象 **28** 脉 · 舌诊 **22** 舌象 · 推拿 **19** 手法 + 天河水五法 + **23** 小儿穴 + **14** 套保健流程

---

## 一、怎么用

**直接双击 `index.html`**（或把它拖进浏览器窗口）。

不需要 Node、不需要服务器、不需要装任何东西，断网也能用。
换台电脑？把整个 `JellyTCM` 文件夹拷过去就行——U 盘、网盘、压缩包都可以，路径随便放。

> 建议用 Chrome / Edge / Firefox 等现代浏览器。IE 不行。

### 3D 经络人体

`图表 → 3D 经络人体`：canvas 手写渲染的可旋转**人形**模型（五官、胸骨中线、锁骨、乳头、脐、脊柱、肩胛、手指脚趾均有体表标志），14 条经脉 + 24 个常用穴位。

- 拖拽旋转、滚轮 / **双指捏合**缩放（0.5×~2.8×）、双击暂停自转（手机上轻点穴位看注解）
- 右上角**朝向徽标**（正面 / 背面 / 左右侧），不再分不清前胸后背
- 悬停穴位出现准星与名称气泡，显示**定位 / 主治 / 功效**
- 右侧可按单条经脉筛选

### 经脉循行动画

`图表 → 十二经脉`：气血自肺经始，按十二时辰依次流注，光点沿线行走、走过之处留下轨迹。
可播放 / 暂停 / 下一经 / 重置，也可直接点某一时辰跳到该经；下方附十二经脉主治对照表。
**鼠标停在图上或说明文字上会暂停，移开继续**——方便边看边对照，不会被动画带跑。

## 三、数据存在哪里？（重要）

学习记录**不在文件夹里**，而在**浏览器的 localStorage**：

- 键名：`jellytcm-v1`（旧版 `tcm-study-v1` 会自动迁移）
- 也就是说：**复制文件夹不会带走学习记录，只带走题库和界面**
- 清浏览器缓存、换浏览器、用无痕窗口 → 记录会丢

### 换设备 / 备份的正确姿势

1. 旧电脑打开 `#/data` → **下载 JSON 备份**（几十 KB）
2. 新电脑打开同一份网页 → `#/data` → **导入**
3. 选「合并」保留现有并取优，或「覆盖」清空后恢复

备份文件长这样：

```json
{ "app":"JellyTCM", "version":2, "exportedAt":"...", "key":"jellytcm-v1",
  "data":{ "cards":{...}, "wrong":{...}, "daily":{...}, "streak":{...}, "settings":{...} } }
```

**建议每周导出一次。**

### 复习节奏

`新学 → 10 分钟 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天 → 60 天 → 120 天`，共 10 个记忆阶段。
答错立刻掉回第 0 阶段并在 5 分钟后重来，所以错题会很快再次出现。

## 四、快捷键

| 键 | 作用 |
|---|---|
| `A` `B` `C` `D`（或 `1`–`4`） | 答题时选择选项 |
| `Enter` / `Space` | 答完后进入下一题 |
| `Ctrl + K` / `⌘ + K` | 全局搜索（方剂 / 药材 / 歌诀 / 六经） |
| `Esc` | 关闭搜索 |
| 右上角 `⌕` `◐` | 搜索 · 主题切换 |

搜索支持模糊匹配与**拼音首字母**：输入「桂枝」能同时找到桂枝汤、桂枝这味药、桂枝汤歌诀；输入 `gz` 直接出桂枝、桂枝汤，`xch` 出小柴胡汤。

版本号自动从 `app\index.html` 读，产物落在仓库同级目录，命名 `JellyTCM-v<版本>.zip`，
内部结构是单个 `JellyTCM` 文件夹（含 `index.html` / `README.md` / `assets`），解压双击即用。

## 七、已知边界

- 插图是**写意示意图**，写生图是**按文字性状参数化绘制的**，两者都用来看「取的是哪个部位」「长什么样、断面什么色」，
  **不能替代药典图谱与实物鉴定**；真要买药认药，请以《中国药典》与专业鉴定为准。
- ② 号位的实拍照片随包附带（416 味全有），但**图源是公开网络**，个别只有带水印或商品图；
  它是「长这样」的辨识参考，**不能替代药典图谱与实物鉴定**。想换成自己拍的，按上面「换自己的图」操作。
- 脉象页只讲**分候原理与脉形特征**，不写「某病必见某脉」；六轴刻度条是**粗略的相对刻度**，不是量化诊断。
  脉诊只是四诊之一，**单凭脉不能定证、更不能定病**。
- 伪品条目为**常见混淆品**的通行记载，各地市场情况不同，仅供预警。
- 穴位定位为示意，真实取穴需结合解剖标志（如「两骨之间」「横纹上 2 寸」）。
- 3D 人体是**空间关系示意模型**，经脉走向与穴位分区按经典记载简化，不能替代骨度分寸取穴。
- 《伤寒论》收的是**精要条文**（170 条，按「辨证要点 + 有方可用」筛选），不是 398 条全本；
  条文依宋本通行文字，编号为本站「篇·序」，非宋本条号。
- 十八反十九畏为**古代配伍禁忌的经验总结**，其中部分并无确凿毒性证据，但药典与处方审核仍视为禁忌，考试按禁忌记。
- 方剂剂量为**古籍记载 + 现代临床常用参考量**，`g` 数仅作学习参考；汉代一两约 13.8g，但一剂常分三服，
  **不能按古方原量直接照抓**。
- 本站是学习工具，**不构成诊疗建议**；处方用药须由执业中医师辨证确定。
